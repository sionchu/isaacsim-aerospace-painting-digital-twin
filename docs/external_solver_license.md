# External solver and asset licensing

The public repository contains the project code, checked-in reference cases,
metrics, and reviewed media.  It does not vendor an OpenFOAM installation,
Isaac Sim binaries, raw NVIDIA assets, third-party CAD, or generated local USD
files.

The reference cases were executed with the OpenCFD/Keysight OpenFOAM v2606
Ubuntu package.  Users must obtain and use that external distribution under its
current license and package terms.  Solver outputs in this repository are
identified as reference evidence and are not presented as an online solver
dependency of the native runtime.

The repository Apache-2.0 license applies only to original code and
documentation in this repository.  It does not grant rights to NVIDIA Isaac
Sim assets, third-party CAD, external solver installations, or generated files
that are not checked in.
